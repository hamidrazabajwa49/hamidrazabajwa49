**Lead Qualifier Agent** — a multi-agent lead-qualification pipeline, built for the Google × Kaggle 5-Day AI Agent Intensive capstone, powered directly by the **Gemini API**.

A raw inbound lead moves through a chain of purpose-built agents: a **security checkpoint** screens it for spam and prompt injection, an **enricher** builds out a company profile, a **scoring agent** rates it against an ideal-customer profile, and a **routing step** either auto-approves it or flags it for **human review** when confidence is low.

→ [`lead-qualifier-agent`](https://github.com/hamidrazabajwa49/lead-qualifier-agent)
