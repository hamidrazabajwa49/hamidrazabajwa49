## 🧠 Who Am I?

I'm a **Computer Science student** obsessed with the math behind intelligence. I build **GenAI pipelines and autonomous agents** with LangChain, LangGraph, and Google's Agent Development Kit — and I believe the best engineers understand *why* something works before reaching for the library that does it for them.

That's the whole idea behind the project below 👇

> *Pattern recognition in chess, physics, and neural nets — turns out it's all the same game.*

## 🤖 Featured Build — Lead Qualifier Agent

<table>
<tr>
<td width="100%">

**A multi-agent lead-qualification system**, built on **Google's Agent Development Kit** for the Google × Kaggle 5-Day AI Agent Intensive capstone.

It takes a raw inbound lead and runs it through a full agentic pipeline: a **security checkpoint** screens for spam and prompt injection, a **lead enricher** builds a company profile via an MCP toolset, a **scoring agent** rates fit against an ICP, and a **routing layer** either auto-approves high-confidence leads or pauses for **human-in-the-loop review** on borderline ones.

`Google ADK` `Gemini 2.5` `MCP` `FastAPI` `Docker` `Terraform`

**[→ View the repo](https://github.com/hamidrazabajwa49/lead-qualifier-agent)**

</td>
</tr>
</table>

## 📚 The 60-Project From-Scratch Challenge

This is **not** a 60-day sprint — it's **60 individual AI/ML systems, built from raw math up**, no `sklearn.fit()` shortcuts, at whatever pace lets each one be done properly. Every module ships with its own README, unit tests, and worked derivations.
