## 🔭 Currently Building

<details open>
<summary><b>🤖 Lead Qualifier Agent</b> — multi-agent lead-qualification pipeline</summary>
<br>

Built for the **Google × Kaggle 5-Day AI Agent Intensive** capstone, powered directly by the **Gemini API**. A raw inbound lead is passed through a chain of purpose-built agents:

`security checkpoint` → `lead enricher` → `scoring agent` → `human-review routing`

The security agent screens for spam and prompt injection, the enricher builds a company profile, the scoring agent rates fit against an ideal-customer profile, and low-confidence leads get routed to a human instead of auto-approved.

**[→ Explore the repo](https://github.com/hamidrazabajwa49/lead-qualifier-agent)**

</details>

## 🗂️ Portfolio Highlights

<details>
<summary><b>🗳️ Pakistan Elections Win Prediction</b> — caught a leakage bug that made a model "predict" the past</summary>
<br>

Found a feature that was mathematically guaranteed to equal 1.0 for every winner — a restated outcome disguised as a predictor. Rebuilt the pipeline leakage-free; ROC-AUC dropped honestly from a suspicious 0.9995 to a real 0.9093.

**[→ Repo](https://github.com/hamidrazabajwa49/pakistan-elections-win-prediction)**

</details>

<details>
<summary><b>🚦 NYC Traffic Volume Prediction</b> — same-day traffic leak caught before it shipped</summary>
<br>

Merged two mismatched fiscal-year datasets, fixed a same-day traffic-count leak, and rebuilt with a leak-free historical baseline recomputed inside each CV fold. Tuned Gradient Boosting: **R² = 0.744**.

**[→ Repo](https://github.com/hamidrazabajwa49/nyc-traffic-volume-prediction)**

</details>

<details>
<summary><b>💳 Credit Card Fraud Detection</b> — investigated a "too perfect to be real" result</summary>
<br>

One model scored a perfect 1.0000 on every metric — instead of celebrating, audited it feature-by-feature and correctly traced it to synthetic-data separability, not target leakage.

**[→ Repo](https://github.com/hamidrazabajwa49/credit-card-fraud-detection)**
