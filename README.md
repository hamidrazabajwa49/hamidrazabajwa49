## 🧠 Who Am I?

I'm a **Computer Science student** obsessed with the math behind intelligence. I build **GenAI pipelines and autonomous agents** using LangChain and LangGraph, and I'm currently running a **60-day AI/ML from-scratch challenge** — implementing everything from linear algebra to research papers in pure Python.

I believe the best engineers understand *why* things work, not just *how* to use them. That's why I start from fundamentals and build upward.

> *Pattern recognition in chess, physics, and neural nets — turns out it's all the same game.*
